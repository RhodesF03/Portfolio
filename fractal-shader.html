Overview

This project implements a real-time fractal renderer using a custom shader. The shader generates complex fractal patterns (such as Mandelbrot or Julia sets) entirely on the GPU, allowing smooth zooming, colour cycling, and parameter animation. The result is a visually rich, mathematically driven effect suitable for games, visualisers, or interactive art tools.

Technical Breakdown

This shader renders a 3D fractal using ray marching over a signed distance field. Each pixel casts a ray into the scene, advancing based on the SDF’s distance estimate until it intersects the fractal. The fractal is formed by iterative transformations applied to a 3D point, with parameters like scale and rotation driving the final structure. Surface normals are derived from the SDF gradient for simple lighting and colour effects.

Mandelbulb Distance Estimator (DE)

The core mathematical function that defines the 3D fractal structure.


float mandelbulbDE(vec3 p, out float smoothIter)
{
    vec3 z = p;
    float dr = 1.0;
    float r = 0.0;

    const int iter = 12;
    const float power = 8.0;

    for(int i = 0; i < iter; i++) {
        r = length(z);
        if(r > 2.6) break;

        float theta = acos(z.z / r);
        float phi = atan(z.y, z.x);

        dr = pow(r, power - 1.0) * power * dr + 1.0;

        float zr = pow(r, power);
        theta *= power;
        phi *= power;

        z = zr * vec3(
            sin(theta) * cos(phi),
            sin(theta) * sin(phi),
            cos(theta)
        ) + p;
    }

    smoothIter = float(i) - log(log(r)) / log(power);
    return 0.5 * log(r) * r / dr;
}

Ray‑Marching Loop

Sphere‑tracing the fractal using the distance estimator to safely advance the ray.


float shortestDistance(vec3 eye, vec3 ray, float start, float end)
{
    float depth = start;

    for (int i = 0; i < MAX_MARCHING_STEPS; i++)
    {
        float h;
        float dist = mandelbulbDE(eye + depth * ray, h);

        if (dist < EPSILON)
            return depth;

        depth += dist;

        if (depth > end)
            return end;
    }

    return end;
}

SDF Normal Estimation

Approximating the surface normal using gradient sampling.


vec3 estimateNormal(vec3 p)
{
    float h;

    return normalize(vec3(
        mandelbulbDE(vec3(p.x + EPSILON, p.y, p.z), h) -
        mandelbulbDE(vec3(p.x - EPSILON, p.y, p.z), h),

        mandelbulbDE(vec3(p.x, p.y + EPSILON, p.z), h) -
        mandelbulbDE(vec3(p.x, p.y - EPSILON, p.z), h),

        mandelbulbDE(vec3(p.x, p.y, p.z + EPSILON), h) -
        mandelbulbDE(vec3(p.x, p.y, p.z - EPSILON), h)
    ));
}

Features

  • Real-time fractal generation entirely on the GPU.
  • Smooth zooming and camera movement.
  • Animated colour palettes driven by time.
  • Parameter controls for iteration count, offset, and zoom.

Challenges & Solutions

  • Precision issues at high zoom levels → improved stability using double-precision emulation.
  • Performance drops with high iteration counts → added dynamic iteration scaling.
  • Colour banding → solved with smoothstep blending and palette interpolation.

Reflection

This shader opened the door to more advanced GPU-driven mathematical rendering. Future work could include 3D fractals, ray-marched fractal volumes, or interactive parameter editing tools for real-time exploration.
