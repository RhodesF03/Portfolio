Overview

This project is a Nonogram/Picross-based educational game designed to support higher education programming students learning Python. Players solve picture logic puzzles where each completed grid reveals and unlocks embedded Python tasks, integrating game-based progression with core programming concepts.

Design Goals

  • Combine familiar puzzle mechanics (Nonogram/Picross) with Python exercises.
  • Encourage repeated engagement and practice through game progression.
  • Support knowledge retention by embedding tasks directly into the puzzle flow.

Technical Overview

The system manages puzzle states, Python task unlocking, and progression tracking. Each puzzle is defined by a grid specification and associated learning objectives. When a puzzle is solved, the game surfaces a Python task, which can be completed within the same flow or via an external environment. 


# Example: simple validation for a Python task
def is_solution_correct(user_output: str, expected_output: str) -> bool:
    return user_output.strip() == expected_output.strip()

Educational Focus

The project was evaluated as part of a university dissertation, comparing game-based materials to traditional written resources for Python learning. Metrics included engagement, perceived difficulty, and short-term retention.

Reflection

Future iterations could expand the task library, add adaptive difficulty based on player performance, and integrate in-game feedback for Python solutions.
