Overview

This project implements a real-time fractal renderer using a custom shader. The shader generates complex fractal patterns (such as Mandelbrot or Julia sets) entirely on the GPU, allowing smooth zooming, colour cycling, and parameter animation.

Technical Breakdown

The fractal shader computes each pixel by iterating a complex function until divergence. The number of iterations determines the colour, producing the characteristic fractal patterns. Parameters such as zoom level, iteration count, and colour palette are animated over time to create dynamic visual effects. 


// Example fragment shader snippet for fractal rendering
uniform float time;
uniform vec2 resolution;
uniform float zoom;
uniform vec2 offset;

vec3 palette(float t) {
    return vec3(0.5 + 0.5 * cos(6.283 * (t + vec3(0.0, 0.33, 0.67))));
}

void main() {
    vec2 uv = (gl_FragCoord.xy / resolution - 0.5) * zoom + offset;

    vec2 z = uv;
    int iterations = 0;
    const int maxIterations = 200;

    while (iterations < maxIterations && dot(z, z) < 4.0) {
        z = vec2(
            z.x * z.x - z.y * z.y + uv.x,
            2.0 * z.x * z.y + uv.y
        );
        iterations++;
    }

    float t = float(iterations) / float(maxIterations);
    gl_FragColor = vec4(palette(t), 1.0);
}

Features

  • Real-time fractal generation entirely on the GPU.
  • Smooth zooming and camera movement.
  • Animated colour palettes driven by time.
  • Parameter controls for iteration count, offset, and zoom.

Challenges & Solutions

  • Precision issues at high zoom levels → improved stability using double-precision emulation.
  • Performance drops with high iteration counts → added dynamic iteration scaling.
  • Colour banding → solved with smoothstep blending and palette interpolation.

Reflection

Building a 3D fractal with ray‑marched SDFs taught me a lot about precision, step sizing, and performance in real‑time rendering. Managing deep zoom levels and complex distance fields pushed me to refine my ray‑march loop and optimise iteration limits to avoid artefacts. It was a solid introduction to more advanced procedural graphics, and sets the foundation for future work like better lighting, shadows, and more complex SDF compositions.
